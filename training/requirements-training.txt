# Pinned Python ML dependencies for the AWARE 2.0 Modal training job
# (Phase 3, ADR-020 Decision 2).
#
# Pinned to specific versions for reproducibility. Bumping any of
# these requires a re-validation run (the bring-up script's
# `--profile training` rebuilds the image and dry-runs a 1-pair job).
#
# The big three (training-optimizer, TRL, peft) are the load-bearing ones.
# Everything else is a transitive dep of one of those, pinned to
# match their version constraints.
#
# Tested against: Python 3.10, CUDA 12.4, torch 2.4.x with cu124
# wheels. The Dockerfile.training image is built FROM nvidia/cuda:12.4.
#
# Version envelope rationale (post-trained-model bump, 2026-06-11):
# - unsloth 2025.4.1: first stable release with Qwen3 LoRA support
# - trl 0.15.0: DPOTrainer + Qwen3 chat-template compatibility fix
# - transformers 4.51.0: Qwen3 architecture introduced
# - peft 0.14.0: LoRA init changes needed for newer Qwen attention
# - accelerate 1.1.0: bnb 4-bit CPU-offload + Qwen3 tokenizer fix
# - bitsandbytes 0.45.0: Qwen3 tensor-parallel bug fixed
# - torch 2.4.1: STAY on 2.4.x — torch 2.5/2.6 broke some training-optimizer paths
